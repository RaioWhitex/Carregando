# 🔄 Animated Loading Spinner UI

Uma interface moderna de indicador de carregamento (Loading Spinner) desenvolvida com foco em simplicidade, fluidez e experiência do usuário. O projeto apresenta uma animação circular suave, ideal para representar processos de carregamento, envio de dados ou espera por respostas em aplicações web.

---

## 📸 Preview do Projeto

Interface contendo:

- Spinner circular animado
- Efeito de rotação contínua
- Design minimalista
- Animação suave e fluida
- Layout centralizado
- Estrutura leve e elegante

---

- **CSS3**

## 🚀 Objetivo do Projeto

Praticar habilidades de desenvolvimento front-end através da criação de um componente de carregamento animado, explorando conceitos de animações CSS, transformações e feedback visual para o usuário.

---

## 📚 Funcionalidades

- Animação automática de carregamento
- Rotação contínua do spinner
- Estrutura reutilizável

- Compatível com diversos projetos web
- Adaptação para diferentes dispositivos
